# VoltLogic Examples

Example circuit labs and built-in sub-circuit definitions for [VoltLogic](https://github.com/CharlesLennon/voltlogic).

## Structure
- `voltlogic-examples.json`: Versioned bundle of showcase circuit labs (including the D366 300A Contactor Hold-On Interlock with PLC Control Bus Duct, Automotive 4-Pin & 5-Pin Relay Harness, Full Adder, RC LED, NMOS Inverter, and 4-Bit Counter) and built-in sub-circuits.
- VoltLogic automatically syncs from `https://raw.githubusercontent.com/CharlesLennon/voltlogic-examples/main/voltlogic-examples.json` on startup and via **SYNC GIT** in the Labs tab.
